# 展示用ショップの外観と入店演出（#28）

## 採用した方向

既存の黒・ブルー／シアン系と、左カメラ＋右の商品選択を維持する。
別のカタログや商品詳細画面へ移動せず、その場で選択・装着・体験する。
参考画像は機械式パネルの雰囲気だけを参照し、CSS/SVGで独自に構成した。

- `intro.js`：回路線→ロゴ点灯→認証→装甲パネルが開く。約3秒。
  カメラ・Three.js・MediaPipeの読込とは独立し、SKIP／Escapeで終了できる。
  動きを減らす設定では省略する。再生ボタンは映像下の右端。
- `exhibition.css`：既存の画面構成・映像とcanvasの座標関係を維持して外観を調整。
- 商品画像は配布GLBからBlenderでレンダー。HEADの画像カードは既存の耳モデル選択に接続。
- 計測表示はスタッフ設定から切替。アクション設定は折りたたみ。
  撮影は既存のPNG保存を維持し、#22の購入・QRは今回実装していない。
- メイン画面も入店演出に合わせ、黒い金属面・細いアイスブルーの輪郭・角を落としたボタンへ統一。
  ロゴ、見出し、技術情報のフォント階層を整理し、Windowsのローカルフォントを優先する。
  撮影ボタンはカメラアイコン付きにし、映像の下部中央に配置する。
- デスクトップの右側は詳細部分だけスクロールし、装着／RESETを表示領域内に残す。
  モバイルでは元の縦並びを使う。カテゴリはネイティブbuttonとaria-pressedで選択状態を示す。
- collection.jsはカメラ・外部モデルを待たずに商品画像を表示する。
  装備操作・撮影は既存main.jsの初期化が済むまで無効にし、準備後に有効化する。
- 腕カードを押すと、その腕モデルを映像に即時プレビューする。プレビュー中は発射・炎・装着音を開始しない。
  APPLY後に装着演出とアクションへ進み、BACKは試着を保持し、RESETは腕を非表示に戻す。
  main.jsとexperience.jsは公開export変更に合わせたキャッシュ更新用queryを付ける。

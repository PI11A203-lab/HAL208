`.blend1`等の自動backupはgit対象外です。既存ファイルを上書きする生成操作は行いません。

## GLB規格

- `EarLeft` / `EarRight`：左右一つずつの独立したnode。本人の左右。最新版は生え際接続点がpivot。
- GLBのworld座標で **X=横、+Y=先端、+Z=正面**。
- 一つの耳は幅約1、高さ約1.55。正面図の左耳pixel(145,331)をpivot、290pxを1単位として制作。装着板はpivotより下にも伸びる。
- ブラウザーは顔幅×`EAR_MODEL.faceWidthScale`（現在0.42）×サイズで拡縮。モデル自体の外向き輪郭を保ち、頭の姿勢のみ適用する。
- GLB耳はHairSegmenterの髪maskから頭頂付近の左右輪郭を取り、額(103/332)ではなく側頭部へ配置する。髪の推論は400ms間隔、800ms以上輪郭が取れなければ顔から外側位置を推定する。横位置・高さはHEADで調整可能でRESET時に0へ戻す。
- 生画像・maskは保存しない。輪郭位置は顔幅で正規化して保持し、顔の移動・拡縮・傾きに毎フレーム追従する。
- Blenderでは **X=横、+Z=先端、-Y=正面**で制作し、glTFの標準`+Y Up`変換でexportする。
- Blenderで左右を見比べるためrootをXにずらしてよい。ローダーは各rootのworld回転/scaleを保ち、制作上のworld平行移動だけを除去して追跡位置へ配置する。
- root以外に原点補正の親を増やす場合も、両rootのworld座標と寸法を確認する。
- Meshは必ず各rootの子孫に配置する。左右rootを入れ子にしない。
- `EarShell`：色入力で変更する外殻材質（必須）。`EarInner`（内板）、`EarHardware`（金具）、`EarGasket`（溝/ゴム）、`EarMarkings`（文字）は外殻色と独立。
- 腕や目のmaterialを使い回さない。左右耳同士の共有は可。
- textureを追加するならGLBに同梱。rootの負scaleによる左右反転は使わず、左右を別meshとして確認する。

# 光の表現の素材

## `fire-flipbook.jpg`（指先の火・ロケットフィストの噴射）

| 項目 | 内容 |
|---|---|
| 内容 | 炎の連番画像。8×8＝64コマ（1コマ 96×192 ピクセル、全体 768×1536）。左上から右へ、上から下へ再生し、最後のコマは最初のコマにつながる（ループ） |
| 背景 | 黒。加算合成で重ねるため透明度は持たない |
| 容量 | 約 0.2 MB |
| 作り方 | `make-fire-flipbook.py`（2次元の流体シミュレーション：燃料・温度・煙・渦）で計算し、温度を色（暗い赤→橙→黄→白）に変換 |
| 出典・ライセンス | HAL208 チームのオリジナル（スクリプトで生成、外部素材なし）。スクリプトの作成と生成にAI（Claude）を使用 |

- 再生の設定（コマ数・速さ・炎の付け根の位置）は `js/config.js` の `FIRE_FLIPBOOK` です。
- 噴射（FIST）では同じ画像の色を青系に入れ替えて使います（`js/flame.js` の `swap`）。
- 作り直す時：`python3 make-fire-flipbook.py fire.png --preview preview` を実行し、PNG を JPEG（品質88）に変換して置き換えます。炎の形はスクリプト内の燃焼・浮力・渦の値で変わります。

## プラズマ弾・閃光・衝撃波・火花・ネット・ケーブル

画像は使わず、`js/fx.js` のシェーダー（ノイズ）で描いています。光る物は `js/bloom.js` でにじませます（`Effects quality` が HIGH の時）。
